盲盒定价建模

热销款为什么定 142?拖动参数,看模型怎么回答。对应 memory/plan.md 的四段推理。

① 定价自洽:确认款期望价值 vs 盲盒价

6 个常规款 + 1 个隐藏款(335)。盲盒售价 108。

② 反推价格敏感度:收入最大化 P* = 1/b

需求 D = a·e−bP,收入 R = P·D,在 P = 1/b 处取最大。观测价格 → 隐含 b。曲线已归一化到峰值 = 1。

热款冷款

前提:商家定价是最优的,且卖得出去。冷款买家对价格更敏感,热款粉丝愿意多付。

③ 多项 Logit:份额与最优加价

sᵢ ∝ exp(αᵢ − β·Pᵢ),最优加价 Pᵢ − c = 1/(β(1−sᵢ))。下面的销量是示意值,请换成真实 SKU 销量。α 由销量和现价反推,再迭代求理论最优价,与现价对比。

现价模型最优价

理论价 > 现价 → 还有提价空间(库存约束/清仓价假设);理论价 < 现价 → 现价偏高。这里按每款独立 FOC 迭代;严格的多品类垄断在 logit 下是统一加价,可视作上界对照。

④ 动态库存:热款涨价、冷款缓降

每天重新计算:剩余 Q 件、T 天,价格取 P = ln(aT/Q)/b(刚好在周期内卖完):库存紧(Q < T·a/e)→ 高于 1/b 且随库存减少上升;积压 → 低于 1/b 并逐步下调,不低于残值。2 个热款 + 4 个冷款,整合套装需要 6 款都有货。

热款(价/库存)冷款(价/库存)

热/冷款的 b 取 1/142 与 1/86(来自②)。热款库存见底 → 价格上冲;热款先卖光 → 套装下架,冷款只能单卖,继续缓降。上游决策(是否继续拆盒)取决于下一盒期望边际收入是否大于 108。

⑤ 反推商家利润:拿货折扣 → 各渠道每盒利润

官方价 129/盒(整套 774),卖家单盒售价 108,隐藏款 335,概率 1/72。成本 c = 129 × 拿货折扣。每盒利润 = 收入×(1−平台费) − 运费 − c。

盈亏平衡折扣:拆盒确认款与折扣、冷款售出率共同决定;卖盲盒 108 的平衡点 = (108×(1−费率)−运费)/129。冷款售出率低于 100% 时,拆盒卖确认款比直接卖盲盒更吃亏,这是"减少拆盒"决策的来源。

仅为教学性建模,销量、成本等为示意参数。
