# Modeling_BlindBox:盲盒系列的需求估计与定价

## Goal

为一个盲盒系列建立需求与最优定价模型,并回答五个问题:热销款为什么是这个价格、库存积压时价格会怎么走、卖家的利润大约有多少、卖家怎样才能找到更好的价格,以及开一盒、卖单款、卖套装都在消耗同一份库存时应该开多少盒.

这是一个 modeling 项目:需求估计、离散选择和库存约束下的收益优化. 项目用了真实的公开价格,但没有真实销量,所以它演示的是方法和一个决策工具,不对这个卖家做实证结论.

[交互页面](https://arcadianlyric.github.io/Modeling_BlindBox/)(拖动参数查看结果).

## Results

数据来自某淘宝卖家的公开价格:6 个常规款 142 / 136 / 88 / 89 / 84 / 84,1 个隐藏款 335,单盒 108,确认款整套 618,不拆封整套 732. 官方售价 129/盒、774/套,隐藏款概率 1/72.

**1. 定价自洽.** 6 个常规款均价 103.8,计入隐藏款后拆一盒的期望收入约 107,与单盒售价 108 几乎相等,说明卖家把"确认款期望价值 ≈ 盲盒价"作为定价锚. 确认款整套 618 只比单买合计 623 便宜 5 元,几乎没有折扣. 不拆封 732 比 618 贵 114. 隐藏款替代一个常规款,所以隐藏款的机会价值只有 6/72 × (335 − 103.8) ≈ 19.3,剩余约 94.7 是原封、大盒和开盒体验的溢价.

**2. 142 隐含的价格敏感度.** 在指数需求 D = a·e^(−bP) 下,利润最大化价格为 P* = c + 1/b,所以观测价格隐含 b = 1/(P − c). 取 c = 0 时,142 对应 b ≈ 0.0070,冷款 84 到 89 对应 b ≈ 0.0115,热款买家的价格敏感度约为冷款买家的 60%. 这不是测量结果,而是"价格已经最优且成本为零"两个假设的推论,而且 c 变大后这个比值会变. 它能解释一个价格,但不能检验这个价格对不对.

**3. 谁拥有这六款,最优价格就不同.** 在共同的价格敏感度 β 下,独立卖家(每款一个卖家)各自满足 Pᵢ − c = 1/(β(1−sᵢ)),越热门的款加价越高. 同一个卖家拥有六款时则最大化总利润,多项 Logit 的最优解是对每款相同的加价. 页面默认值(β = 0.02, c = 60)下,独立卖家的价格约为 124 / 121 / 112 / 112 / 111 / 111,单一卖家对六款都定 144. 所以对一个转卖商来说,仅靠人气不足以解释热款卖 142、冷款卖 84,溢价必须来自稀缺性(结果 6)或不同的价格敏感度.

**4. 滚动清仓规则让价格保持平稳,而不是上涨.** 每天把价格重设为 P = ln(a·T剩余/Q剩余)/b,也就是让期望需求刚好用完剩余库存的价格,这会使库存与剩余天数的比例保持不变. 没有噪声时,默认参数下热款价格稳定在约 182,冷款约 81. 随机销量下出现的涨跌来自噪声、整数销量和最后几天,而不是规则本身. 这是启发式,不是最优动态策略,后者需要对库存和时间求价值函数 [3].

**5. 卖家利润.** 成本无法由价格唯一识别,只能给出区间. 默认参数下(拿货折扣 75%、平台费 1%、运费 4 元/单、冷款售出率 85%、未售出库存按标价 50% 处理),每盒利润约为:

| 渠道 | 每盒利润(元) |
|---|---|
| 卖盲盒 108 | 6.2 |
| 拆盒卖确认款 | 1.0 |
| 确认款整套 618 | 4.6 |
| 不拆封整套 732 | 23.4 |

单卖盲盒的盈亏平衡折扣约为 80%. 拆盒卖确认款的利润几乎全靠拿货折扣,冷款卖不完时比直接卖盲盒更差. 不拆封整套是毛利最厚的渠道.

**6. 开盒、单款价格和套装价格是同一个决策.** 开一盒会把一个未拆盒变成一个随机款,确认套装消耗每个常规款各一个,原封套装消耗六个未拆盒. 这就是网络收益管理的结构:套装相当于多航段行程,开盒相当于随机增加运力 [4]. 页面用流体近似求解:对每个开盒数量,在期望销量不超过供给的约束下,为十个选项(未拆盒、原封套装、确认套装、六个单款、隐藏款)定价,需求采用选项各自价格敏感度的多项 Logit [5],再用随机模拟检验计划. 默认值下(240 个未拆盒、60 天、日访客 20、观测价格处弹性 3、残值 50%,需求参数全部是假设):

- 计划开 170 / 240 盒,比全部不拆多赚 10,858,比全部拆开多赚 3,200. 最优点上,开一盒和不拆的影子价值相同(94.3),这就是开盒规则的精确形式:只有当一盒作为随机款的期望价值高于它不拆时的价值,才再开一盒.
- 一个卖家、所有选项弹性相同时,所有选项相对有效成本的加价相同. 计划中热款价格(198 到 206)远高于冷款(94 到 100),因为热款的影子价格约 76 到 79,冷款只有约 16. 这是结果 3 的另一面:这里热款溢价来自稀缺.
- 随机模拟(每种策略 20 次):每天用实际剩余库存重新求解的计划收入加残值为 31,549,静态计划 30,541,保持现价且任何款缺货就拆盒为 25,805. 把计划的开盒数量逐日分批开出以保留选择权为 29,819,比一次开完少 1,730,因为确认套装要六款都有货,逐日开盒时 60 天里只有 27 天能卖套装,一次开完是 56 天.

**7. 找更好的价格需要改价测试.** 第二个价格点打破了结果 2 的循环:设现价 P₀ 下日销量为 D₀,测试价 P₁ 下为 D₁,则斜率 b = ln(D₀/D₁) / (P₁ − P₀). 剩余 Q 件、T 天时,周期利润为 (P − c)·min(D(P)·T, Q);没有库存限制时在 c + 1/b 处最大,库存紧时不低于清仓价 P₀ + ln(D₀T/Q)/b. 页面默认值下推荐价格为 200(即支付意愿上限),60 天比 142 多赚 8,700,但仍会在约第 47 天售罄. 做这个模块得到三条经验:

- 测试几乎不改变销量时,b 很小,1/b 会爆炸. 从 142 测到 225、销量只从 5.0 降到 4.7,隐含的最优价接近 1400,这是外推,不是建议. 页面设了支付意愿上限,并对超出测试区间 30% 以上的最优价给出警告.
- 如果涨价后销量上升,b 无法估计. 真实数据里这通常说明噪声、促销、断货或两个时段的需求变化,而不是"价格高更好卖".
- 可靠的做法是迭代:把价格向模型最优价移动一部分,再测一次,重新估计.

## Discussion

**价格内生性是核心的识别难题.** 它出现在两个层面. 跨款式时 β 根本不可识别:每款有自己的 αᵢ,又只有一个价格—销量点,所以反推 αᵢ 之后任何 β 都能完全拟合销量. 随时间看时,同一款的价格仍然不是外生的:卖家按需求定价,热门款同时有高 αᵢ 和高价格. 直接用观测价格回归会混淆人气和价格,使 β 偏向 0,让需求看起来没那么价格敏感 [2]. 出路有两条:像离散选择文献那样给价格找工具变量,或者做随机化价格变化. 结果 7 走的是第二条:改价测试就是对价格做 A/B 实验,同样的工具适用,包括每组足够多的天数让销量差异超过日间噪声,以及检查两组之间没有其他变化.

- 利润表依赖假设的拿货折扣. 真实值应该用各款已售数量回归得到:先估出 β 和各款 αᵢ,再由 c = Pᵢ − 1/(β(1−sᵢ)) 反推成本,6 款结果应基本一致,差异大说明"定价最优"不成立,价格可能锚定了竞品. 注意这个反推要与所有权假设一致,独立卖家和单一卖家的公式不同.
- 页面第三个模块的销量(40 / 35 / 12 / 13 / 11 / 10)是示意值,不是真实数据.
- 结果 6 的联合模型建立在假设的需求参数上(弹性、访客数、套装和未拆盒的效用偏移),数字展示的是机制,不是这个卖家的最优解. 模型里卖家已知需求,所以推迟开盒没有学习价值;现实中等到看出哪款会火再开盒,价值可能比模拟显示的更高.
- 模型里开出的盒是独立随机款. 真实的原封套装常常每个常规款各一个,这会减轻库存失衡.
- 流体计划是在开盒数量网格上用影子价格下降求解的,所以最优开盒数只精确到网格步长.
- 没有考虑竞品卖家、官方补货和二级市场溢价,这些都会改变需求曲线. 模型假设商品为正品,赝品成本更低,会改变模型.

## Material and methods

- 需求:指数需求 D = a·e^(−bP),利润最大化价格 P* = c + 1/b.
- 款间需求:多项 Logit,份额 sᵢ = exp(αᵢ − βPᵢ) / (1 + Σⱼ exp(αⱼ − βPⱼ)) [1,2],αᵢ 由销量和现价反推. 独立卖家:Pᵢ − c = 1/(β(1−sᵢ)),用阻尼迭代求解. 单一卖家:Pⱼ − cⱼ = 1/βⱼ + Π,其中 Π 满足 Π = Σⱼ exp(αⱼ − βⱼcⱼ − 1 − βⱼΠ)/βⱼ(牛顿法),共同 β 下是统一加价.
- 库存定价:滚动清仓启发式,每天按剩余库存和剩余天数重设价格.
- 联合开盒与定价:在 8 种库存(6 个常规款、隐藏款、未拆盒)和 10 个选项上做流体近似,βⱼ = ε / 观测价格ⱼ. 对给定的开盒数量,库存的影子价格 μ 由对偶问题的投影下降得到;给定 μ 后,价格是单一卖家最优解,每个选项的有效成本为它消耗的每单位库存的残值加 μ. 开盒数量在网格上选取. 模拟使用泊松日访客、在有货选项间做 logit 选择,四种策略共用同一组随机数.
- 利润:每盒利润 = 收入 × (1 − 平台费) − 运费 − 129 × 拿货折扣.
- 改价测试:b = ln(D₀/D₁) / (P₁ − P₀);周期利润 (P − c)·min(D(P)·T, Q);最优价 = min(max(c + 1/b, P₀ + ln(D₀T/Q)/b), 上限). 需求不随价格下降时拒绝估计.
